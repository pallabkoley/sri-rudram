<h2>📖 About Project</h2>

<p>
  Sri Rudram is a web-based spiritual platform that combines temple information,
  Pooja booking, devotional content, and online shopping through Siddha Store.
  It includes a customer-facing website and an admin panel to manage bookings,
  products, orders, and website content.
</p>

<h2>✨ Key Features</h2>

<h3>🌐 Frontend</h3>
<ul>
  <li>Home Page and Temple Information</li>
  <li>Spiritual Services and Pooja Information</li>
  <li>Siddha Store for Spiritual Products</li>
  <li>Devotional Content, Gyan, Articles, and Festivals</li>
</ul>

<h3>🔐 Admin Panel</h3>
<ul>
  <li>Dashboard and Booking Management</li>
  <li>Temple, Pooja, and Bhet Management</li>
  <li>Product and Order Management</li>
  <li>User, Article, Gyan, Festival, and FAQ Management</li>
  <li>Reviews, Coupons, Subscribers, Reports, and Settings</li>
</ul>

<h2>⚙️ Installation & Setup</h2>

<ol>
  <li>Clone the repository.</li>
</ol>

<pre><code>git clone https://github.com/pallabkoley/sri-rudram.git</code></pre>

<ol start="2">
  <li>Place the project inside the XAMPP <code>htdocs</code> directory.</li>
  <li>Start Apache and MySQL from the XAMPP Control Panel.</li>
  <li>Create the database and import the project SQL file, if available.</li>
  <li>Update the database credentials in the existing configuration file.</li>
  <li>Open the project through localhost in your browser.</li>
</ol>

<h2>🔒 Security</h2>

<ul>
  <li>Validate user inputs and use secure database queries.</li>
  <li>Restrict administrative access to authorized users.</li>
  <li>Keep database credentials secure.</li>
</ul>
