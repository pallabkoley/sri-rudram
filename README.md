<h2>📖 About Project</h2>

<p>
  Sri Rudram is a web-based spiritual platform that brings religious services,
  devotional content, and spiritual shopping together in one place. Users can
  explore Pooja services, access spiritual information, and browse products
  through Siddha Store. The platform also includes an admin panel for managing
  bookings, products, orders, and website content.
</p>

<h2>✨ Key Features</h2>

<h3>🌐 Frontend</h3>
<ul>
  <li>Home Page with spiritual information and website highlights.</li>
  <li>Temple Information and Pooja Booking.</li>
  <li>Siddha Store for browsing spiritual products.</li>
  <li>Devotional Content, Gyan, Articles, and Festivals.</li>
</ul>

<h3>🔐 Admin Panel</h3>
<ul>
  <li>Dashboard for accessing administrative features.</li>
  <li>Temple, Pooja, and Bhet Management.</li>
  <li>Booking, Product, and Order Management.</li>
  <li>User, Article, Gyan, Festival, and FAQ Management.</li>
  <li>Reviews, Coupons, Subscribers, Reports, and Settings.</li>
</ul>

<h2>⚙️ Installation & Setup</h2>

<ol>
  <li>Clone the repository:</li>
</ol>

<pre><code>git clone https://github.com/pallabkoley/sri-rudram.git</code></pre>

<ol start="2">
  <li>Place the project inside the XAMPP <code>htdocs</code> directory.</li>
  <li>Start Apache and MySQL from the XAMPP Control Panel.</li>
  <li>Create the database and import the project SQL file, if available.</li>
  <li>Configure the database credentials in the existing configuration file.</li>
  <li>Open the project through your local server in a browser.</li>
</ol>
